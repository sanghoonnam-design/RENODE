ISBC 보드 가상 테스트 (Renode)
==============================

ISBC 보드(회로도 V0.4)를 PC에서 가상으로 돌리는 도구입니다.
실기와 같이 부트로더가 먼저 돌고, 그 위에 올린 앱 펌웨어(ELF)로 넘어갑니다.
설치는 필요 없습니다. Renode와 Python(PySide6)이 이 폴더 안에 들어 있습니다.


0. 처음 받았을 때 주의
----------------------
- zip을 연 상태에서 바로 실행하지 말고, 반드시 "압축 풀기"를 한 뒤 실행합니다.
- 바탕화면, 다운로드, C:\ISBC 처럼 얕은 폴더에 풉니다. 아주 깊은 폴더에 풀면
  Windows 경로 길이 제한(260자) 때문에 "파일 이름이 너무 깁니다" 오류가 날 수 있습니다.
- 경로에 ; 나 " 문자가 없어야 합니다. 공백과 한글은 괜찮습니다.
- 실행할 때 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"을 누릅니다.
  (서명되지 않은 프로그램이라 뜨는 경고입니다)
- Windows 10/11 64비트에서 실행합니다. 관리자 권한과 별도 설치는 필요 없습니다.


1. 실행
-------
1) 이 폴더를 원하는 곳에 압축 해제합니다. (위 "0. 처음 받았을 때 주의" 참고)
2) "ISBC 보드 가상 테스트.bat"을 더블클릭합니다.
3) 창 위쪽 "앱 ELF" 칸에서 올릴 펌웨어를 고릅니다.
   - 기본값: apps\Vial_Decapper.elf (예시 앱)
   - 내 앱: STM32CubeIDE에서 Debug 빌드한 .elf를 "찾아보기"로 선택
   - "부트로더만(앱 없음)": 앱 없이 부트로더만 구운 보드 상태
4) "Renode + UART 열기"를 누릅니다.
   - Renode Monitor 창과 USART1 창이 열립니다.
   - 몇 초 뒤 창 왼쪽에 3D 보드가 나타납니다.
5) 펌웨어 부팅에 30~90초 걸립니다. USART1 창에 앱 시작 문구가 나온 뒤
   오른쪽 "TCP 명령"에서 "연결"을 누르고 VER 등을 보냅니다.

코드를 고친 뒤에는: CubeIDE에서 Debug 빌드 → Renode 창들을 닫기 → 다시 "Renode + UART 열기".


2. 연결 정보
------------
- USART1 (USB CLI 콘솔) : Renode의 USART1 창에 직접 입력. 화면 지우기 CLC, 글자 지우기 Backspace
- TCP 명령              : 127.0.0.1:18000  (펌웨어 TCP 8000, 명령 끝에 CRLF)
- 펌웨어 웹             : http://127.0.0.1:18080  (펌웨어 80, 부트로더만일 때는 Firmware Update 페이지)
- 3D 보드 화면          : http://127.0.0.1:18100  (창 안에 표시, 브라우저로도 열 수 있음)
같은 PC에서 Renode를 두 개 띄우면 포트가 겹쳐 열리지 않습니다. 이전 Renode를 먼저 닫으세요.


3. 가상 보드에 들어 있는 것
---------------------------
PCB_1: STM32F746, ISBC 부트로더(ISBC_Bootloader_260413), W5300 이더넷, AT24C256 EEPROM,
       LED0~3, DIP 스위치 PSW0~3(모두 OFF), SD 카드 감지(카드 없음), USART1/USART2/UART4
PCB_2: TMC429 모션 컨트롤러, TMC2660 드라이버 x2, MCP23S17 IO 확장 x2(입력 16점, 출력 16점)

아직 모델이 없는 것(동작하지 않음): AD7124 온도, SD 카드 읽기/쓰기, CAN, RS485 통신, ADC, PWM 출력.

EEPROM 내용은 isbc-renode\isbc-eeprom.bin 에 저장되어 다시 켜도 유지됩니다.
지우면 빈 EEPROM으로 시작합니다.


4. Renode Monitor에서 직접 쓰기 (선택)
--------------------------------------
Renode Monitor에 아래처럼 입력하면 IO 입력을 켜고 끄거나 출력 상태를 볼 수 있습니다.
  sysbus.spi1.io SetInput 3 true      (IN3 ON)
  sysbus.spi1.io Outputs              (OUT0~15 상태, 비트 1 = ON)
  sysbus.spi5.tmc429 GetPosition 0    (모터 축 0 위치)


5. 폴더 구성
------------
ISBC 보드 가상 테스트.bat : 실행
apps\                    : 예시 앱 ELF
isbc-renode\             : 가상 ISBC 보드(Renode 스크립트, 모델, 부트로더, 3D 화면, 창 프로그램)
renode_1.17.0-portable\  : Renode 1.17.0
python\                  : Python 3.14 + PySide6 6.11 (창 실행용)
